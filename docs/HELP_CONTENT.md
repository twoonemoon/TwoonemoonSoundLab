# Встроенная справка и подсказки

> Файл сгенерирован `Scripts/tools/gen_help_doc.py` из `Source/UI/HelpContent.cpp` — правьте исходник, затем перегенерируйте.

## Разделы справки (страница «Справка», поиск по названию, тексту и ключевым словам)

### Подключение гитары

Подключите гитару в инструментальный (Hi-Z) вход аудиоинтерфейса. В standalone-приложении выберите устройство в меню «Настройки аудио» (Cmd+,), в DAW создайте моно-дорожку с входом гитары и вставьте плагин. Вход 1 = Left (In 1) — режим по умолчанию.

*Ключевые слова:* вход интерфейс подключение hi-z устройство

### Уровень входа

Играйте громко и смотрите на индикатор In внизу слева. Пики должны быть заметно ниже красной зоны. Слишком тихий вход — меньше перегруза и больше шума, слишком громкий — клиппинг АЦП интерфейса (его не исправить плагином). Регулируйте сначала усилением интерфейса, затем ручкой Input.

*Ключевые слова:* уровень input индикатор клиппинг громкость

### Задержка (латентность)

Плагин не добавляет задержку к основной цепочке. Общая задержка складывается из буфера аудиоинтерфейса и драйвера: для живой игры выберите 32–128 сэмплов. Исключение — голоса Pitch, Octave (Poly) и Harmonizer: сдвинутые голоса запаздывают на ~20–40 мс, прямой сигнал — нет.

*Ключевые слова:* задержка латентность буфер latency

### Пресеты

Страница «Пресеты»: категории, поиск, избранное (звезда) и недавние. Двойной клик — загрузить. Стрелки ←/→ листают пресеты. «Сохранить как…» создаёт пользовательский пресет; заводские пресеты защищены от изменений.

*Ключевые слова:* пресеты сохранить загрузить избранное

### A/B сравнение

Кнопки A и B на странице «Игра» хранят два варианта настроек. Переключайтесь между ними, чтобы сравнить. «Копия в другой» дублирует текущий вариант.

*Ключевые слова:* a/b сравнение

### Отмена изменений

Cmd+Z — отменить, Cmd+Shift+Z — повторить. История хранит до 100 шагов.

*Ключевые слова:* отмена undo redo

### Цепочка эффектов

Страница «Цепочка»: перетаскивайте модули, чтобы изменить порядок. Клик по индикатору — включить/выключить, двойной клик — настройки модуля. Параллельная секция делит сигнал на пути A и B, Parallel A/B Mix смешивает их.

*Ключевые слова:* цепочка порядок параллельно модули

### Усилители

12 моделей в четырёх категориях. Gain — перегруз предусилителя, Master — раскачка оконечного каскада. Advanced: Sag (проседание питания), Bias (смещение ламп), Feedback (обратная связь). Модели — собственные схемы, не копии существующих усилителей.

*Ключевые слова:* усилитель amp gain master bias sag

### Кабинет и IR

Встроенные кабинеты — алгоритмические модели динамиков и микрофонов (не измерения). Перетаскивайте микрофон на диффузоре: центр ярче, край темнее. «Загрузить IR…» принимает WAV (PCM 16/24/32 или float, моно/стерео, любая частота; длиннее 350 мс обрезается).

*Ключевые слова:* кабинет ir микрофон wav импульс

### Гармонайзер

Выберите тональность (Key) и лад (Scale), включите голоса и выберите интервалы. Гармонайзер определяет ноту по чистому сигналу гитары и рассчитан на одноголосные мелодии: аккорды не гармонизируются по отдельным нотам.

*Ключевые слова:* гармонайзер harmonizer тональность лад интервал

### Тюнер

Кнопка «Тюнер» в шапке или клавиша T. Сыграйте открытую струну: стрелка и строб показывают отклонение в центах, зелёный — точно. Mute глушит выход на время настройки.

*Ключевые слова:* тюнер настройка строй

### MIDI Learn и педаль экспрессии

Правый клик по ручке → «MIDI Learn», затем пошевелите контроллер — CC будет привязан. Педаль экспрессии назначается так же (обычно CC 11). Диапазон и инверсия — в «Настройках». Привязки сохраняются в проекте.

*Ключевые слова:* midi learn педаль экспрессия cc контроллер

### Масштаб интерфейса

Кнопка с процентами в шапке: 50, 75, 100, 150, 200, 250%. Интерфейс векторный и перерисовывается в нужном размере. 50% — компактный режим: маленькое окно с пресетом, основными регуляторами усилителя, шестью эффектами и тюнером, шрифты остаются читаемыми. Кнопка «Полный интерфейс» внизу возвращает 100%. Масштаб запоминается.

*Ключевые слова:* масштаб размер окно компактный маленький

### Эквалайзер

Страница EQ: пять параметрических полос, срезы низа и верха и анализатор спектра до и после эквалайзера. Точки на графике перетаскиваются мышью: по горизонтали — частота, по вертикали — уровень. Эквалайзер — отдельный модуль цепочки, его место можно менять.

*Ключевые слова:* эквалайзер eq анализатор спектр полоса

### Лупер

Страница «Эффекты» → Looper. Rec — запись первой петли (до 30 секунд), повторное нажатие — воспроизведение. Rec или Overdub во время воспроизведения — наложение. Stop/Play — остановка и запуск с начала, Clear — стереть. Петля записывается в конце цепочки и не стирается при смене пресета.

*Ключевые слова:* лупер looper петля запись наложение

### Метроном

«Настройки» → «Метроном»: щелчки 4/4 по ручному темпу или темпу DAW (при игре транспорта — синхронно с тактами). Акцент выделяет первую долю.

*Ключевые слова:* метроном клик темп

### Утилиты

Stereo Widener расширяет стерео (бас ниже Mono Below остаётся в моно, индикатор корреляции показывает моносовместимость). Output Limiter — защитный ограничитель на выходе без задержки. Оба по умолчанию выключены.

*Ключевые слова:* утилиты widener limiter стерео ограничитель

## Знакомство (первый запуск, повтор — «Настройки → Показать знакомство снова»)

1. **Добро пожаловать** — TwoonemoonSoundLab — гитарный процессор: усилители, кабинеты и эффекты. Пять коротких шагов помогут начать. Их можно пропустить и открыть снова в «Настройках».
2. **1. Подключите гитару** — Гитара — в инструментальный вход 1 аудиоинтерфейса. В standalone-приложении выберите устройство в меню «Настройки аудио» (Cmd+,). Внизу слева — выбор входа.
3. **2. Проверьте уровень** — Сыграйте громко: индикатор In внизу слева должен заметно не доходить до красного. При необходимости уменьшите усиление интерфейса или ручку Input.
4. **3. Громкость выхода** — Ручка Output внизу справа — общая громкость. Начните с небольшой громкости мониторов или наушников.
5. **4. Выберите звук** — Кнопки «Быстрый старт» — Clean, Heavy, Ambient, Acoustic. Больше вариантов — на странице «Пресеты».
6. **5. Настройте гитару** — Кнопка «Тюнер» в шапке (или клавиша T). Приятной игры!

## Подсказки регуляторов (наведение курсора; отключаются в «Настройках»)

Параметров: 261. Подсказка показывается для каждого.


### Global

| Регулятор | Ключ | Подсказка |
|---|---|---|
| Input | `global.input` | Уровень гитары на входе цепочки. Играйте громко: индикатор In не должен доходить до красного. Двойной клик — сброс. |
| Output | `global.output` | Общая громкость выхода. Меняет только уровень, не характер звука. |
| Bypass | `global.bypass` | Полный обход обработки — слышен исходный сигнал гитары. |
| Input Mode | `global.inputMode` | Какой вход аудиоинтерфейса использовать: обычно гитара подключена во вход 1 (Left). |
| Tuner Mute | `global.tunerMute` | Глушит выход, пока вы настраиваете гитару. |
| A4 Reference | `global.tunerRef` | Эталонная частота ноты Ля первой октавы для тюнера (обычно 440 Гц). |
| Tempo | `global.tempo` | Ручной темп для синхронизации задержки и модуляций (если темп хоста не используется). |
| Follow Host Tempo | `global.hostTempo` | Брать темп из DAW, когда он доступен. |
| Oversampling | `global.oversampling` | Качество обработки нелинейностей усилителя. Live 2x — меньше нагрузка, High 8x — меньше искажений-артефактов на верхах. Задержку не добавляет. |

### Gate

| Регулятор | Ключ | Подсказка |
|---|---|---|
| Gate On | `gate.on` | Включить/выключить модуль. Переключение плавное, без щелчков. *(общий для переключателей)* |
| Gate Threshold | `gate.threshold` | Уровень, ниже которого сигнал считается шумом. Поднимайте, пока не исчезнет шум в паузах, но ноты ещё не обрываются. |
| Gate Attack | `gate.attack` | Как быстро гейт открывается при атаке ноты. |
| Gate Hold | `gate.hold` | Сколько гейт держится открытым после того, как сигнал упал ниже порога — защищает затухающие ноты. |
| Gate Release | `gate.release` | Скорость закрытия гейта. Больше — мягче и естественнее, меньше — резче для рубленых риффов. |
| Gate Hysteresis | `gate.hysteresis` | Разница между порогами открытия и закрытия: не даёт гейту «дребезжать» на затухающих нотах. |
| Gate Range | `gate.range` | Насколько глушить шум: −90 дБ — полная тишина, −20 дБ — лёгкое приглушение. |
| Gate Key | `gate.key` | Local — гейт слушает сигнал в своей точке цепочки; Input DI — чистый сигнал гитары (точнее при сильном перегрузе). |
