# Архитектурные решения (ADR)

## ADR-001. Фреймворк: iPlug2
**Статус:** принято (2026-10-22).
**Контекст:** нужны AUv2, VST3, CLAP, standalone на macOS ARM64; без платных лицензий; открытый код.
**Проверено:** `ThirdParty/iPlug2/LICENSE.txt` (commit 39ea73a) — zlib-like, разрешает модификацию и распространение,
совместима с GPL-3.0. Встроенные зависимости: WDL (zlib-like), NanoVG/NanoSVG (zlib), MetalNanoVG (MIT),
RtAudio/RtMidi (MIT), nlohmann/json (MIT). CMake-интеграция (`iplug_add_plugin`) с целями `-app/-vst3/-clap/-au`
фактически собрала все 4 формата.
**Альтернативы:** JUCE — GPL/коммерческая двойная лицензия, требование пользователя «без платной лицензии»
выполнимо только под AGPL/GPL, но отказ от JUCE снимает вопрос полностью. DPF — нет AUv2. Своя обвязка
над CLAP + clap-wrapper — больше риска.
**Решение:** iPlug2 (submodule, закреплён по SHA), графика IGraphics + NanoVG + Metal.

## ADR-002. Лицензия проекта: GPL-3.0-or-later
**Статус:** принято. Все зависимости (iPlug2 zlib-like, VST3 SDK MIT, CLAP MIT, шрифты OFL-1.1) совместимы.
VST3 SDK с версии 3.8 распространяется под MIT — двойной лицензии GPLv3/проприетарной больше нет.

## ADR-003. Форматы
AUv2 (`aumf`, т.к. принимается MIDI для Learn/экспрессии), VST3 (`Fx|Distortion`), CLAP, standalone.
AAX не выпускается (закрытый SDK, отдельные условия Avid). AUv3 — не в текущем объёме.

## ADR-004. Минимальная macOS: 12.0
Apple Silicon поставлялся с macOS 11+. Используемые API (Metal, CoreAudio, AppKit) доступны в 12.0;
декоративные эффекты не требуют новых API. **Фактически протестировано только на macOS 26.6.2.**
Повышать минимум только при реальной необходимости.

## ADR-005. Сборка без полного Xcode
Лицензия Xcode на машине разработки не принята → сборка через Command Line Tools + CMake/Ninja.
Standalone без `.xib` (программное меню, `AppBootstrap.mm`). SDK выбирается автоматически (`Scripts/env.sh`).

## ADR-006. Ядро DSP отдельно от фреймворка
`TwoonemoonCore` (static lib) не включает заголовков iPlug2: DSP тестируется собственным тестовым
раннером, движок можно переиспользовать. Внутренняя обработка — float, на границе с iPlug2 (double) —
конверсия в преаллоцированных буферах.

## ADR-007. Параметры: X-macro реестр, состояние по ключам
Индекс параметра = ID хоста (append-only). Состояние плагина сохраняется как пары (key, value) + порядок
цепочки по ключам модулей → новые версии корректно читают старые проекты, отсутствующие параметры получают
default, неизвестные игнорируются.

## ADR-008. Оверсэмплинг: полифазные IIR halfband
Минимальная задержка (группа ≈ единицы отсчётов на НЧ, без lookahead) против линейно-фазовых FIR. Цена —
нелинейная фаза у верхней границы полосы, на гитарном сигнале несущественно. Плагин сообщает хосту
латентность 0, т.к. это не чистая задержка; фактическая групповая задержка документируется в DSP_DESIGN.md.

## ADR-009. Смена порядка цепочки
Порядок публикуется из UI через seqlock (двойной буфер + счётчик), audio thread применяет его после
короткого затухания (~12 мс) и сброса состояний модулей — без аллокаций и без щелчков.
