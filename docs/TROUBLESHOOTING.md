# Решение проблем

## Звук и аудиоустройство

| Симптом | Причина и решение |
|---|---|
| Нет звука в приложении | «Настройки → Аудиоустройство и буфер…» (Cmd+,): выберите интерфейс для входа и выхода. Проверьте выбор входа внизу слева (`Left (In 1)` для входа 1). Убедитесь, что не включены Bypass с нулевым Output или Mute тюнера. |
| Индикатор In не двигается | гитара подключена в другой вход — переключите `Input Mode`; в «Системные настройки → Конфиденциальность → Микрофон» разрешите доступ приложению TwoonemoonSoundLab. |
| Щелчки, треск, пропадания | увеличьте размер буфера (128–256), выберите Oversampling «Live 2x», выключите неиспользуемые модули; закройте тяжёлые программы. |
| Большая задержка при игре | уменьшите буфер (32–128) в настройках аудио или DAW; голоса Pitch/Octave Poly/Harmonizer запаздывают на 20–40 мс по природе алгоритма — используйте Octave «Mono (analog)» для мгновенного отклика. |
| Звук искажён даже на clean-пресете | клип на входе интерфейса — уменьшите усиление интерфейса (индикатор In не должен краснеть), затем Input. |
| Слишком тихо/громко после смены пресета | заводские пресеты выровнены по уровню; общую громкость задаёт Output. Свои пресеты выравнивайте ручкой Amp Level / Volume. |
| Гул и шум в паузах | включите Noise Gate, поднимайте Threshold; для high-gain выберите ключ «Input DI». Проверьте заземление и одиночные звукосниматели. |
| Звук «моно» в наушниках | цепочка моно, пока стерео не создаст эффект: кабинеты с панорамой, стерео-задержка/реверберация/хорус. Stereo Widener на моно-сигнале не действует. |

## DAW и плагин

| Симптом | Решение |
|---|---|
| Плагин не виден | перезапустите DAW или запустите повторное сканирование (таблица в INSTALLATION.md). Проверьте, что установлен нужный формат и для нужной схемы (системная / пользовательская папка). |
| Logic не показывает AU | Logic: «Настройки → Плагины» → найдите Twoonemoon → «Повторно проверить». Из Терминала: `auval -v aumf TmSL Twmn` должно вывести «AU VALIDATION SUCCEEDED». |
| Плагин виден дважды | установлены и пользовательская, и системная копии (часто после сборки из исходников). Удалите лишнюю: `Scripts/uninstall.sh --user`. |
| Ableton не видит VST3 | включите «Use VST3 Plug-in System Folders» и нажмите Rescan. |
| Задержка дорожки | плагин сообщает латентность 0. Если DAW показывает задержку — это буфер DAW или другой плагин. |
| Загружается не тот IR / IR пропал | пользовательские IR хранятся по пути; если файл перемещён или удалён, слот показывает ошибку — загрузите IR заново. |

## Установка

| Симптом | Решение |
|---|---|
| «Не удаётся проверить разработчика» | сборка без подписи Developer ID: правый клик → «Открыть» или «Конфиденциальность и безопасность → Всё равно открыть». Gatekeeper отключать не нужно. |
| «Установка не удалась… ошибка при запуске скриптов» | по пути установки найден посторонний бандл с тем же именем, но другим идентификатором — установщик его не трогает. Посмотрите подробности: «Окно → Журнал установщика» (или `/var/log/install.log`, строки TwoonemoonSoundLab), переименуйте/удалите посторонний файл сами и повторите. |
| Нужен пароль администратора | установка «для всех пользователей». Без пароля — «Установить только для меня». |
| «Нужен Mac с Apple Silicon» | пакет только для arm64; на Intel не устанавливается. |

## Сборка

| Симптом | Решение |
|---|---|
| `You have not agreed to the Xcode license agreements` | скрипты переключаются на CLT сами; для своих команд используйте `export DEVELOPER_DIR=/Library/Developer/CommandLineTools` или примите лицензию: `sudo xcodebuild -license accept`. |
| Ошибка линковки с `arm64e.x1` / tbd | новейший SDK не поддерживается линкером CLT — `Scripts/env.sh` выбирает подходящий SDK автоматически; если вызываете cmake вручную, задайте `-DCMAKE_OSX_SYSROOT=<путь к MacOSX26.5.sdk>`. |
| `cmake`/`ninja` не найдены | `python3 -m venv ~/.tonelab-tools && ~/.tonelab-tools/bin/pip install cmake ninja`. |
| Нет VST3/CLAP SDK | `Scripts/bootstrap.sh` (нужен доступ к github.com). |
| `ibtool` / `metal` недоступны | не нужны: standalone собирается без `.xib`, шейдеры NanoVG предкомпилированы. |
| Тесты падают после изменения DSP | `Scripts/test.sh` выводит имя теста и проверку; рендеры для анализа — `tsl_render --render <папка>`. |

## Сброс настроек

Закройте приложение/DAW и удалите `~/Library/Application Support/TwoonemoonSoundLab/settings.json` — масштаб,
подсказки, анимации и признак знакомства вернутся к значениям по умолчанию. Пресеты лежат в `Presets/` той же папки.
Повреждённый файл настроек игнорируется автоматически (используются значения по умолчанию).
