## CPU и задержка (`tsl_bench`, одно ядро M1, оффлайн-обработка)

| Цепочка | 48 кГц, блок 64, 4x | 2x | 8x | 96 кГц, 4x |
|---|---|---|---|---|
| gate + amp (Brass Circuit) + cab | 2.05 % | 1.20 % | 3.64 % | 4.16 % |
| clean amp (Lumen Twin) + cab | 1.57 % | 0.91 % | 2.84 % | 3.25 % |
| heavy: gate + dist + amp (Catacomb) + cab | 3.03 % | 2.02 % | 4.83 % | 5.98 % |
| все 25 модулей + двойной кабинет | 6.92 % | 5.92 % | 8.77 % | 16.18 % |

Латентность всех цепочек — 0 сэмплов. Групповая задержка оверсэмплинга усилителя (НЧ, 4x): 6.12 отсчёта =
**0.128 мс** при 48 кГц. Голоса Pitch/Octave Poly/Harmonizer: ≈ 20 мс (Live) / ≈ 40 мс (Smooth).
Это измерения обработки без хоста; реальная нагрузка в DAW зависит от хоста и буфера.

## Пресеты (`tsl_render --calibrate`, синтетический сигнал «щипок струны», 48 кГц)

60 пресетов: RMS моно-суммы **−20.0…−19.6 dBFS** (громкость выровнена), NaN/Inf нет. Пики: у большинства −12…−2 dBFS,
у пяти пресетов выше −1 dBFS (Glass Morning, Studio DI Clean, Tremolo Surf, Major Pentatonic Duet — чистые звуки
с большим пик-фактором; Underwater Phase +1.8 dBFS). Underwater Phase: стерео-фазер разводит фазы каналов, моно-сумма,
по которой считается RMS, частично гасится, и нормировка поднимает каналы — особенность метода замера, а не перегрузка
обработки. Синтетический сигнал не заменяет прослушивание.
