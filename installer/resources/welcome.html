TwoonemoonSoundLab @VERSION@

Бесплатный гитарный процессор с открытым исходным кодом (GPL-3.0): 12 моделей усилителей, кабинеты и IR, педали и эффекты, эквалайзер, тюнер, пресеты.

Что будет установлено (лишнее можно отключить на шаге «Тип установки» → «Настроить»):

  • приложение TwoonemoonSoundLab.app — в «Программы»;
  • Audio Unit — в Library/Audio/Plug-Ins/Components;
  • VST3 — в Library/Audio/Plug-Ins/VST3;
  • CLAP — в Library/Audio/Plug-Ins/CLAP.

Для всех пользователей или только для вас. По умолчанию установка выполняется для всех пользователей этого Mac (папки /Applications и /Library) — macOS запросит пароль администратора. Чтобы установить без пароля только для себя (~/Applications и ~/Library), на шаге «Выбор места» нажмите «Установить только для меня».

Обновление. Если TwoonemoonSoundLab уже установлен, старые версии компонентов будут заменены. Ваши пресеты, настройки и загруженные IR хранятся отдельно (~/Library/Application Support/TwoonemoonSoundLab) и не изменяются.

Установщик не меняет настройки безопасности macOS и конфигурацию ваших DAW. Требуется Mac с Apple Silicon и macOS 12 или новее.
