# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — семантические.

## [0.1.0] — 2026-10-22 — первая тестовая версия (не релиз)

Первая полная сборка для ручного тестирования. Звучание ещё не прослушано на реальной гитаре; подписи
Developer ID и нотаризации нет.

### Форматы и платформа
- AUv2 (`aumf`, TmSL/Twmn), VST3, CLAP и самостоятельное приложение для macOS 12+ на Apple Silicon.
- Сборка с одними Command Line Tools (CMake + Ninja), закреплённые SDK: iPlug2, VST3 SDK 3.8.1 (MIT), CLAP.

### Звук
- Движок с нулевой добавленной задержкой: выбор входа, Input/Output, Bypass, измерители, защита от NaN и
  перегрузки, плавная смена порядка цепочки и пресетов, параллельная секция A/B.
- 12 оригинальных моделей усилителей (clean, crunch, high gain, acoustic): каскады триодов с динамическим смещением,
  пассивный tone stack, двухтактный оконечный каскад с Bias, Sag, ООС с Presence/Depth; оверсэмплинг 2/4/8x.
- Cab Studio: 6 синтезированных кабинетов × 3 микрофона, положение/дистанция/угол, два слота A/B, пользовательские
  WAV IR, свёртка с нулевой задержкой.
- Noise Gate (ключ DI), Compressor, Boost, Overdrive, Distortion, Fuzz.
- 5-полосный параметрический EQ с анализатором до/после.
- Delay (Digital, Tape, Analog, Ping-Pong, Multi-Tap), Reverb (Room, Hall, Plate, Spring, Shimmer, Freeze).
- Chorus, Phaser, Flanger, Tremolo, Vibrato, Rotary, Envelope Filter.
- Wah, Octave (Mono/Poly), Pitch Shifter (WSOLA-подобный), 4-голосный диатонический Harmonizer.
- Stereo Widener, Output Limiter, Looper (30 с), метроном.
- Хроматический тюнер (NSDF), строб, Mute.

### Работа и интерфейс
- 60 заводских пресетов в 7 категориях с выровненной громкостью; пользовательские пресеты, избранное, недавние,
  поиск, импорт/экспорт; A/B; отмена/повтор (100 шагов).
- Страницы: Игра, Пресеты, Цепочка (перетаскивание), Усилитель (12 фасадов), Кабинет, Эффекты, EQ, Настройки, Справка.
- MIDI Learn для любого регулятора, педаль экспрессии, диапазон и инверсия.
- Масштаб 50–250%; при 50% — компактный режим с отдельной раскладкой.
- Знакомство при первом запуске, справка с поиском, подсказки у всех 261 параметра.
- Иконка приложения.

### Установка и инструменты
- Единый установщик `TwoonemoonSoundLab-Installer.pkg`: выбор компонентов, установка для всех или только для себя,
  безопасное обновление, защита чужих бандлов, скрипт удаления, контрольные суммы; необязательные подпись и
  нотаризация через переменные окружения.
- 68 тестов ядра; скрипты валидации (auval, VST3 validator, pluginval, clap-validator), рендер и калибровка пресетов.
- Документация: архитектура, DSP, арт-дирекшн, сборка, установка, руководство, справка, решение проблем, лицензии,
  выпуск.

### Исправлено по результатам валидации
- CLAP: rescan параметров после загрузки состояния, восстановление без потери точности, запись состояния порциями,
  отклонение чужого состояния, конфигурация аудиопортов, сообщение латентности и длины «хвоста».
